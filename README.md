## 🚀 Funzionalità Principali
*   **Card Profilo Centralizzata:** Visualizzazione della foto profilo con biografia e dettagli essenziali.
*   **Collegamenti Professionali:** Bottoni diretti e ottimizzati per **GitHub**, **LinkedIn** e **Indeed**.
*   **Design Responsive:** Layout flessibile che si adatta perfettamente sia agli schermi dei computer che ai dispositivi mobili (smartphone e tablet).
*   **Sfondo Personalizzabile:** Un pulsante permette ai visitatori di alternare lo sfondo della pagina tra bianco e nero.
*   **Interattività Leggera:** Micro-interazioni ed effetti di hover sui bottoni gestiti tramite CSS e JavaScript per migliorare l'esperienza utente.

---

## 🛠️ Tecnologie Utilizzate
*   **HTML5:** Struttura semantica della pagina.
*   **CSS3:** Styling personalizzato, layout (Flexbox/Grid), animazioni e media queries per il responsive design.
*   **JavaScript (Vanilla):** Gestione di eventuali dinamiche interattive e logiche di click.

   Fai semplicemente doppio click sul file `index.html` per aprirlo direttamente nel tuo browser.

## 🧠 Cosa ho imparato
Questo progetto, seppur strutturalmente semplice, mi ha permesso di consolidare le basi del posizionamento e del **responsive web design** senza l'ausilio di framework esterni (come Bootstrap o Tailwind). Ho approfondito l'uso delle media queries per garantire che la card mantenga proporzioni eleganti su qualsiasi display, prestando attenzione alle performance di caricamento dell'immagine del profilo.
